## 2. نتائج خوارزمية Insertion Sort

**حجم المصفوفة:** N = 100,000 عنصر

**وحدة القياس:** الميكروثانية (µs) والميلي ثانية (ms).

| حالة المصفوفة | الزمن (µs) | الزمن (ms) |
|---|---:|---:|
| غير مرتبة (Random) | 2,063,745 | 2063.745 |
| مرتبة عكسيًا (Reversed) | 4,124,672 | 4124.672 |
| مرتبة جزئيًا (80%) | 445,463 | 445.463 |
| مرتبة تمامًا (Fully Sorted) | 97 | 0.097 |

---

## 4. تحليل النتائج

- **المصفوفة غير المرتبة (Random):** استغرقت الخوارزمية 2063.745 ms.
- **المصفوفة المرتبة عكسيًا (Reversed):** سجلت أعلى زمن، وهو 4124.672 ms.
- **المصفوفة المرتبة جزئيًا (80%):** استغرقت 445.463 ms.
- **المصفوفة المرتبة تمامًا (Fully Sorted):** سجلت أقل زمن، وهو 0.097 ms.

---

## 5. التعقيد الزمني

| الحالة | التعقيد الزمني |
|---|---|
| أفضل حالة | O(N) |
| متوسط الحالة | O(N²) |
| أسوأ حالة | O(N²) |

## 6. الاستنتاج

توضح النتائج أن خوارزمية Insertion Sort تكون فعالة جدًا عندما تكون المصفوفة مرتبة مسبقًا، لكنها تصبح أبطأ عندما تكون البيانات مرتبة عكسيًا أو عشوائيًا، خاصة عند التعامل مع أحجام كبيرة من البيانات.
